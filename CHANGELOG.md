## [0.1.0] - 2026-05-28

### Added
- Monorepo scaffold: Bun workspaces, Vite + React frontend, Hono + Bun backend
- Role-based auth: register, login, logout, sessions (superadmin / admin / client)
- Server management: connect VPS via SSH private key, ping, status
- Live server stats: CPU, RAM, disk via SSH
- Domain management: nginx vhost creation, SSL via Certbot
- Site deployment: static HTML, PHP starter templates
- shadcn/ui component library: button, input, textarea, card, badge, dialog, select, label, separator, progress
- Dashboard with server health overview
- IDEA.md — full product vision and roadmap
- MIT License, CONTRIBUTING guide, this CHANGELOG
